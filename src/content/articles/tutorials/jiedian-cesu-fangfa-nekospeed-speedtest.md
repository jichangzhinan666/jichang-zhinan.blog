测速本身不难，难的是知道自己测的是什么、怎么记录才能和别人（或者一周后的自己）比较。本文把常见工具分成三类，说明各自的含义与局限，然后给出本站使用的记录规范。文中的数字来自本站 2026-11-10 的实测报告，用于说明概念。

## 三类工具各测什么

### 1. 客户端“测试延迟”

Clash Verge Rev、Clash Meta for Android、品牌官方客户端里的闪电图标或“测试延迟”按钮。它向一个固定 URL（Clash 系默认常用 `http://www.gstatic.com/generate_204` 一类的空响应地址）经节点发一次请求，记录耗时。

- **测的是**：本机 → 节点 → 测试 URL 的一次握手 / 请求时间，主要反映到节点的距离与节点响应快慢。
- **不测**：带宽、抖动、丢包、晚高峰拥塞。
- **用途**：快速筛掉超时节点，比较同地区节点的一致性。本站实测报告中的“各地区节点延迟”均来自此类测试，例如[隐形人](/speed-tests/invisible-2026-11-10-hongkong03/)香港 20 个节点 66–73 ms、日本 43–47 ms。

### 2. 浏览器测速：Speedtest / Cloudflare / IPCheck.ing

在开启代理的浏览器里打开测速页面，流量经节点到达测速服务器。

- **测的是**：下载、上传（Mbps）、Ping、抖动，Cloudflare 系（包括 IPCheck.ing 的 Cloudflare 测速）还给出**满载延迟**（下载 / 上传跑满时的延迟）。
- **关键变量**：测速服务器位置。选节点同地区的服务器测的是节点带宽；选国内服务器测的是回程。本站实测统一选节点同地区服务器（HKG、SIN、NRT）。
- **示例**：[飞V 新加坡](/speed-tests/flyv-2026-11-10-singapore/)：下载 900.07 Mbps、上传 529.03 Mbps、Ping 23.9 ms、抖动 2.38 ms、满载下载延迟 35.8 ms；[浪网香港](/speed-tests/langwang-2026-11-10-hongkong/)：下载 218.92 Mbps、上传 3.47 Mbps、抖动 48.49 ms。两组数字放在一起只能说明“各自那一刻的状态”，因为节点、服务器、时段都不同。

IPCheck.ing 还提供 23 项服务的**连通性测试**（ChatGPT、YouTube、Netflix 等的连通延迟）。注意“可用”是连通性判定，不等于账号与地区限制全部解除。

### 3. 订阅批量测速：MiaoKo（喵速）、SpeedCentre 等

把订阅链接交给一台服务器，由它逐个节点测 TLS 握手延迟、HTTPS 延迟与下载速度，输出整张表格。

- **测的是**：服务器所在网络到各节点的带宽上限与延迟，单位 **MB/s**（1 MB/s ≈ 8 Mbps）。
- **局限**：测速端是大带宽服务器线路（本站收录的浪网 2026-07-19 截图标注“珠海联通 9Gbps 32 线程”），与家庭宽带体验无关；截图不一定带时间戳；多线程结果远高于单线程体验。
- **用途**：比较同一订阅内各节点的相对强弱、发现失败节点。本站的[浪网 MiaoKo 报告](/speed-tests/langwang-2026-07-19-miaoko/)与[微风网络截图](/speed-tests/breezenet-miaoko-undated/)属于这一类，页面均标注了单位与转录误差。
- **隐私风险**：这类服务需要你的订阅链接，等于把账号凭据交给第三方。只用自建或完全可信的服务，测完后在机场后台重置订阅链接。本站不提供此类在线工具，原因见[隐私政策](/privacy/#tools)。

## 单位与换算

- Speedtest / IPCheck.ing：Mbps（兆比特每秒）。
- MiaoKo / SpeedCentre：MB/s（兆字节每秒），1 MB/s = 8 Mbps。
- YouTube“详细统计信息”的连接速度：Kbps，÷1000 得 Mbps（例如隐形人报告中 7,128 Kbps ≈ 7.1 Mbps）。
- 1080p 流畅播放通常需要稳定 10 Mbps 以上，4K 需 25 Mbps 以上。

比较任何两个数字前先统一单位，并确认它们来自同类工具。

## 记录规范（本站采用）

每次测试记录以下字段，缺一项就标“未记录”，不要省略：

| 字段 | 示例 |
| --- | --- |
| 测试时间（含时区） | 2026-11-10 11:43（北京时间） |
| 本地网络 | 运营商 + 城市 + 接入方式（光纤 / 5G） |
| 设备与客户端 | Windows 11 / 隐形人客户端 V3.0.0 |
| 品牌与套餐 | 隐形人 白银纪元 |
| 节点名称 | 香港03 |
| 出口信息 | 香港 · Lshiy LLC · AS32167（来自 IP 检测） |
| 工具与服务器 | IPCheck.ing Cloudflare 测速 · HKG |
| 下载 / 上传 | 516.73 / 336.76 Mbps |
| Ping / 抖动 / 满载延迟 | 138.45 ms / 4.19 ms / ↓154.9 ↑141.6 ms |
| 丢包 | 用 `ping -n 100`（Windows）或 `ping -c 100` 记录丢包率 |
| 客户端延迟 | 各地区最低 / 平均 / 最高，超时节点单列 |
| 体验备注 | YouTube 720p 丢帧 1/940 |
| 截图 | 保留工具界面上的时间信息，遮盖订阅标识 |

本站 2026-11-10 的四份报告缺少“本地网络”字段，因此在每份报告中都注明了这一局限并拒绝做跨品牌比较。

## 测试流程建议

1. **固定变量**：同一设备、同一本地网络、同一节点、同一测速服务器。
2. **重复**：每组至少 3 次取中位数。
3. **分时段**：非高峰与晚高峰（20:00–23:00）各一组，连续 3–7 天。
4. **同时记录体验**：测速数字之外记录真实使用（视频清晰度、会议是否掉线）。
5. **不要做的事**：不要把不同工具的数字直接比较；不要用单次白天测速下结论；不要把订阅链接交给不可信的在线测速服务。
