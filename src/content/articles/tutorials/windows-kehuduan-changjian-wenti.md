这篇文章是一份排错清单，按“现象 → 原因 → 处理”组织，覆盖 Windows、iOS、Android 三个平台上最常见的客户端问题。每条都尽量给出能自己验证的步骤。安装与导入的基础流程请先看 [Clash Verge Rev 教程](/tutorials/clash-verge-rev-jiaocheng/)、[iOS 教程](/tutorials/ios-shiyong-jiaocheng/)与 [Android 教程](/tutorials/android-shiyong-jiaocheng/)。

## 先做三件事

任何“连不上”的问题，先花两分钟排除三个最常见的本地原因：

1. **系统时间**：TLS 类协议对时间敏感，系统时间偏差几分钟就可能导致握手失败、全部节点超时。开启“自动设置时间”并同步一次。
2. **订阅状态**：登录机场后台，确认订阅未过期、流量未用尽、节点列表与客户端一致。
3. **换一个网络**：用手机热点再试。能连说明是原网络的问题（公司网络、校园网、路由器设置常见）。

## 全平台通用问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 所有节点超时 | 时间不准 / 订阅失效 / 本地网络限制 / 服务端维护 | 按上文三步排除；看机场公告 |
| 订阅更新失败 | 订阅服务器需先经代理访问；链接被截断；订阅过期 | 先连上任一可用节点再更新；重新复制链接；查后台 |
| 国内网站变慢、提示异地登录 | 模式选成“全局” | 改为“规则”模式 |
| 某些海外网站打不开、其他正常 | 规则把该域名判为直连；节点被目标服务屏蔽 | 在“连接”页看命中规则；换地区节点 |
| 延迟很低但速度很慢 | 延迟不等于带宽；晚高峰拥塞；丢包 | 见[低延迟却速度慢的原因](/wiki/jiedian-di-yanchi-que-sudu-man/) |
| 视频能看但会议卡 | 上传低、抖动大 | 换节点；看报告中的上传与抖动指标，例如本站实测中浪网香港节点上传 3.47 Mbps、灵动云日本5 上传 2.17 Mbps |
| DNS 检测显示本地运营商 | 分流直连属正常；若代理域名也走本地 DNS 才是泄露 | 见 [DNS 泄露如何检测与排查](/tutorials/dns-xielou-jiance-paicha/) |

## Windows

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 启动报 WebView2 错误 | 缺少 Microsoft Edge WebView2 运行时 | 安装运行时，或使用带 fixed webview2 的安装包 |
| 系统代理已开，部分软件不走代理 | 该软件不读取系统代理（游戏、命令行、部分客户端） | 开启 TUN 模式；或在该软件内设置代理地址与端口（端口以客户端设置页显示为准，常见 7890 / 7897） |
| TUN 模式无法开启 | 未安装服务；未以管理员运行；被安全软件拦截 | 设置页“安装服务”→ 重启客户端；允许安全软件放行 |
| 端口被占用 | 其他代理软件或残留进程占用了混合端口 | 关闭其他代理软件；在设置中更换端口 |
| 杀毒软件报毒 | 内核与 TUN 驱动常被启发式误报 | 只从 GitHub Releases 下载；在杀毒软件中添加信任；仍不放心可校验发布页提供的哈希 |
| 关闭客户端后无法上网 | 系统代理未被恢复 | 设置 → 网络和 Internet → 代理，关闭“使用代理服务器” |
| UWP 应用（商店应用）不走代理 | UWP 默认不允许回环代理 | 使用 TUN 模式 |
| 公司 / 校园网连不上 | 网络策略封锁端口或协议 | 换网络；联系机场客服询问是否有备用端口 |

## iOS

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| App Store 搜不到客户端 | Apple ID 地区为中国大陆 | 使用非大陆地区 Apple ID |
| 无法添加 VPN 配置 | 设备管理描述文件限制；系统异常 | 检查“VPN 与设备管理”；重启后重试 |
| 订阅导入后没有节点 | 链接不完整；需先经代理拉取；格式不兼容 | 重新复制；先连其他可用网络；向客服确认格式 |
| 切换 Wi‑Fi / 蜂窝后断连 | 网络切换导致隧道重建 | 正常现象；若长时间不恢复则重新开启 |
| 国内 App 异地登录 | 路由模式选成“代理 / 全局” | 改为按配置分流 |
| 耗电明显 | 后台持续流量；按需连接频繁触发 | 检查是否有应用在后台大量联网；关闭按需连接 |

iOS 上没有“系统代理 / TUN”之分，客户端开启后即接管全部流量，概念见[TUN 模式与全局代理区别](/wiki/tun-moshi-yu-quanju-daili/)。

## Android

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 锁屏后断连 | 定制系统清理后台 | 关闭电池优化、允许自启动与后台运行、锁定最近任务 |
| 没有弹出 VPN 授权 | 已有其他 VPN 应用占用 | 一次只能运行一个 VpnService 应用，关闭其他 |
| 连接成功但网页打不开 | 模式为直连；分应用代理把浏览器排除 | 检查模式与分应用设置 |
| 游戏 / 直播不走代理或卡顿 | 应用使用 UDP；节点不支持 UDP 或 NAT 类型受限 | 换节点；查看节点 UDP 支持，术语见[机场百科](/wiki/) |
| APK 安装被阻止 | 未允许“安装未知应用” | 仅对浏览器 / 文件管理器授权一次 |
| 更新后配置丢失 | 跨版本升级或卸载重装 | 重新导入订阅；提前导出配置 |

## 官方客户端的特殊情况

本站收录的 8 个品牌多数以官方客户端为主（飞V、微风网络、浪网不提供订阅链接）。官方客户端的排错路径更短：确认官网下载、账号状态、系统版本是否在支持范围（例如微风网络资料写明 Windows 10 及以上、macOS 10.15 及以上、Android 5.0 及以上、iOS 15 及以上），然后联系客服。多个品牌资料写明客服可协助处理安装、节点切换、DNS、TUN 等问题（例如灵动云）。各品牌的客服渠道与时间见[品牌资料库](/reviews/)。

## 什么时候该换机场而不是继续排错

- 多个网络、多台设备、时间正确、订阅有效，仍连续多日全部节点超时。
- 晚高峰连续 7 天出现明显不可用，而白天正常（判断方法见[稳定机场怎么选](/guides/wending-jichang-zenme-xuan/)）。
- 客服在资料承诺的时间内无响应。

排错耗时也是成本；月付试用期就是用来发现这些问题的。
